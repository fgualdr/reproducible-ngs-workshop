Public Data Retrieval

Accession logic

For GEO/SRA, teach the hierarchy:

GSE study -> GSM sample -> SRP project -> SRX experiment -> SRR run

ENA and ArrayExpress may provide clearer FASTQ URLs for some datasets. Record the route used.

ENA/ArrayExpress route

The main workshop route starts from the two ArrayExpress SDRF files:

mkdir -p raw_data/metadata

curl -fL \
  https://ftp.ebi.ac.uk/biostudies/fire/E-MTAB-/025/E-MTAB-13025/Files/E-MTAB-13025.sdrf.txt \
  -o raw_data/metadata/E-MTAB-13025.sdrf.txt

curl -fL \
  https://ftp.ebi.ac.uk/biostudies/fire/E-MTAB-/026/E-MTAB-13026/Files/E-MTAB-13026.sdrf.txt \
  -o raw_data/metadata/E-MTAB-13026.sdrf.txt

Keep the original SDRFs unchanged. In VS Code, copy the selected FASTQ rows into raw_data/metadata/selected_fastq_files.csv, use one row per FASTQ file, and replace ftp:// with https:// before saving:

assay,fastq_name,fastq_url
rnaseq,WT_1_condition_A_R1.fastq.gz,https://ftp.sra.ebi.ac.uk/vol1/fastq/ERR114/010/ERR11479310/ERR11479310_1.fastq.gz
rnaseq,WT_1_condition_A_R2.fastq.gz,https://ftp.sra.ebi.ac.uk/vol1/fastq/ERR114/010/ERR11479310/ERR11479310_2.fastq.gz

The maintained download script contains one simple loop:

#!/usr/bin/env bash
set -euo pipefail

metadata="raw_data/metadata/selected_fastq_files.csv"
log_file="results/logs/day1/ena_download.log"

mkdir -p raw_data/fastq/rnaseq raw_data/fastq/chipseq results/logs/day1
: > "${log_file}"

for row in $(tail -n +2 "${metadata}" | tr -d '\r')
do
  IFS=, read -r assay fastq_name fastq_url <<< "${row}"

  echo "Downloading ${fastq_name}" | tee -a "${log_file}"
  curl -fL "${fastq_url}" -o "raw_data/fastq/${assay}/${fastq_name}"
done

This simple for loop is appropriate only because the curated CSV fields contain no spaces.

Optional GEO/SRA route

SRA Toolkit is useful for future projects that do not provide direct FASTQ URLs. The SRA Run Selector exports a large metadata table. For this optional example, create a smaller one-column CSV at:

raw_data/metadata/sra_example.csv

Its header is run_accession, and each following row contains one run to download:

run_accession
SRR11192680
SRR11192681

The optional example below skips the header and downloads both runs:

#!/usr/bin/env bash
set -euo pipefail

csv_file="raw_data/metadata/sra_example.csv"
out_dir="raw_data/fastq/sra_example"

mkdir -p "${out_dir}"

for run_accession in $(tail -n +2 "${csv_file}")
do
  echo "Downloading ${run_accession}"
  fasterq-dump "${run_accession}" \
    --split-files \
    --threads 2 \
    --outdir "${out_dir}"

  gzip -f "${out_dir}/${run_accession}"*.fastq
done

Run that script inside the SRA Toolkit image:

docker run --rm \
  --platform linux/amd64 \
  -v "$PWD:/work" \
  -w /work \
  docker.io/fgualdr/ngs-sra-tools:latest \
  bash scripts/day1/example_sra_run_selector_download.sh

This is an example route, not the main download route for the workshop.

Reproducibility record

Version the accession table. Do not version downloaded FASTQ files.
