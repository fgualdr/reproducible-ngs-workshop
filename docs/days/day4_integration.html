Optional Day 4 - Basic RNA-seq and ChIP-seq integration in R

GRanges, peak-to-gene links and sequence composition

ImportantThis entire page is optional

Day 4 is an optional extension for students who want to practise basic genomic integration in R. It is not required to complete the core FASTQ-to-result workflows from Days 1–3.

1. Aim

The goal is not to build a complete regulatory-network pipeline. The goal is to understand a small set of reusable R/Bioconductor objects and operations:

By the end, you should be able to explain:

  • why a regular table and a genomic interval object are different;
  • how BED and GFF3 become GRanges objects;
  • how distanceToNearest() and findOverlaps() answer different questions;
  • how promoter windows depend on strand;
  • how an indexed FASTA can supply peak DNA sequences;
  • how to calculate GC fraction and CpG counts;
  • why a peak near a differentially expressed gene is a candidate relationship, not proof of direct regulation.

3. The four object types used today

R object Represents Typical operation
data.frame rectangular statistics or metadata filter, sort, merge
GRanges genomic intervals plus metadata overlap, nearest, distance, resize
Hits index pairs connecting two interval sets query and subject extraction
FaFile / DNAStringSet indexed genome on disk / sequences in memory retrieve bases, count letters and motifs

The distinction matters. A data.frame knows that a column is named start, but it does not know that start, end, chromosome and strand form a genomic interval. GRanges does.

5. Import tables, intervals and the indexed genome

Add:

rna <- read.delim(rna_file, check.names = FALSE)
peaks <- import(peak_file, format = "BED")
annotation <- import(annotation_file, format = "GFF3")
genes <- annotation[annotation$type == "gene"]
genome <- FaFile(genome_file)
genome_index <- scanFaIndex(genome)

Inspect the objects:

class(rna)
class(peaks)
class(genes)
class(genome)
class(genome_index)

rna[1:3, ]
peaks[1:3]
genes[1:3]
genome_index

What happened during import?

  • the TSV remained a data.frame;
  • the BED coordinates were converted into a GRanges object;
  • the GFF3 gene features became another GRanges object;
  • FaFile points to the indexed FASTA without loading the whole genome as an ordinary character string;
  • scanFaIndex() returns the sequence ranges available in the FASTA index.

5.1 Add stable peak and gene identifiers

BED column 4 is imported as the name metadata column. Add:

if (!"name" %in% names(mcols(peaks))) {
  stop("Consensus BED must contain peak IDs in column 4")
}
peaks$peak_id <- as.character(peaks$name)
names(peaks) <- peaks$peak_id

GFF3 attribute names vary. Select the first suitable gene-identifier field:

candidate_id_columns <- c("ID", "gene_id", "locus_tag", "Name")
gene_id_column <- intersect(candidate_id_columns, names(mcols(genes)))[1]

if (is.na(gene_id_column)) {
  stop("No suitable gene identifier found in the GFF3 gene features")
}

genes$gene_id <- as.character(mcols(genes)[[gene_id_column]])
names(genes) <- genes$gene_id

Set chromosome lengths from the FASTA index so that interval trimming is explicit:

genome_lengths <- setNames(width(genome_index), as.character(seqnames(genome_index)))
common_seqlevels <- intersect(names(genome_lengths), union(seqlevels(peaks), seqlevels(genes)))

seqlengths(peaks)[common_seqlevels] <- genome_lengths[common_seqlevels]
seqlengths(genes)[common_seqlevels] <- genome_lengths[common_seqlevels]

Check that peaks and genes share sequence names:

shared_sequences <- intersect(seqlevelsInUse(peaks), seqlevelsInUse(genes))
if (length(shared_sequences) == 0) {
  stop("Peaks and genes do not share chromosome names")
}
shared_sequences

6. Nearest gene: a distance question

distanceToNearest() returns a Hits object. Each hit connects one query peak to one nearest subject gene and stores the distance.

Add:

nearest_hits <- distanceToNearest(peaks, genes, ignore.strand = TRUE)
class(nearest_hits)
nearest_hits

Convert the index pairs into a readable table:

nearest_table <- data.frame(
  peak_id = peaks$peak_id[queryHits(nearest_hits)],
  peak_chrom = as.character(seqnames(peaks))[queryHits(nearest_hits)],
  peak_start = start(peaks)[queryHits(nearest_hits)],
  peak_end = end(peaks)[queryHits(nearest_hits)],
  gene_id = genes$gene_id[subjectHits(nearest_hits)],
  gene_strand = as.character(strand(genes))[subjectHits(nearest_hits)],
  distance_to_gene = mcols(nearest_hits)$distance
)

write.table(
  nearest_table,
  file.path(table_dir, "peak_nearest_gene.tsv"),
  sep = "\t", quote = FALSE, row.names = FALSE
)

Interpretation:

  • distance 0 means that the peak overlaps the gene interval;
  • a positive distance means that the peak is outside the gene body;
  • “nearest” does not mean “regulated.” It is a geometric annotation rule.

Plot the distance distribution:

distance_plot <- ggplot(nearest_table, aes(distance_to_gene)) +
  geom_histogram(bins = 40) +
  theme_bw() +
  labs(
    x = "Distance from peak to nearest annotated gene (bp)",
    y = "Number of peaks"
  )

ggsave(
  file.path(plot_dir, "peak_to_nearest_gene_distance.pdf"),
  distance_plot,
  width = 7, height = 5
)

7. Promoter overlap: an interval-overlap question

For this optional exercise, define a strand-aware promoter as 500 bp upstream and 100 bp downstream of the annotated gene start.

promoters() understands gene strand:

promoter_ranges <- promoters(genes, upstream = 500, downstream = 101)
promoter_ranges <- trim(promoter_ranges)
promoter_ranges$gene_id <- genes$gene_id

For a +-strand gene, the promoter extends toward smaller coordinates. For a --strand gene, upstream extends toward larger coordinates.

Find peak-promoter overlaps:

promoter_hits <- findOverlaps(peaks, promoter_ranges, ignore.strand = TRUE)
class(promoter_hits)

Build a table:

promoter_table <- data.frame(
  peak_id = peaks$peak_id[queryHits(promoter_hits)],
  peak_chrom = as.character(seqnames(peaks))[queryHits(promoter_hits)],
  peak_start = start(peaks)[queryHits(promoter_hits)],
  peak_end = end(peaks)[queryHits(promoter_hits)],
  gene_id = promoter_ranges$gene_id[subjectHits(promoter_hits)],
  promoter_start = start(promoter_ranges)[subjectHits(promoter_hits)],
  promoter_end = end(promoter_ranges)[subjectHits(promoter_hits)],
  gene_strand = as.character(strand(promoter_ranges))[subjectHits(promoter_hits)]
)

write.table(
  promoter_table,
  file.path(table_dir, "peak_promoter_overlaps.tsv"),
  sep = "\t", quote = FALSE, row.names = FALSE
)

One peak can overlap more than one promoter, especially in a compact bacterial genome with divergent or closely spaced genes. That is a biological ambiguity, not a software error.

8. Join promoter-associated peaks to RNA-seq results

The interval operation produced a regular table. We can now merge it with the DESeq2 result table by gene identifier.

First confirm the RNA-seq identifier column:

if (!"gene_id" %in% names(rna)) {
  names(rna)[1] <- "gene_id"
}
rna$gene_id <- as.character(rna$gene_id)

Join and classify candidate relationships:

integrated <- merge(promoter_table, rna, by = "gene_id", all.x = TRUE)

integrated$is_de <- !is.na(integrated$padj) &
  integrated$padj < 0.05 &
  abs(integrated$log2FoldChange) >= 1

integrated$candidate_class <- ifelse(
  integrated$is_de,
  "DE gene with promoter-overlapping peak",
  "promoter-overlapping peak without DE evidence"
)

write.table(
  integrated,
  file.path(table_dir, "promoter_peak_rnaseq_integration.tsv"),
  sep = "\t", quote = FALSE, row.names = FALSE
)

candidate_targets <- integrated[integrated$is_de, , drop = FALSE]
candidate_targets <- candidate_targets[order(candidate_targets$padj), , drop = FALSE]

write.table(
  candidate_targets,
  file.path(table_dir, "candidate_regulatory_relationships.tsv"),
  sep = "\t", quote = FALSE, row.names = FALSE
)

The phrase candidate regulatory relationship is deliberate. Promoter-proximal occupancy plus differential expression is stronger combined evidence than either result alone, but it does not establish causality or distinguish direct from indirect effects without additional evidence.

9. Optional: add Day 3 differential-peak statistics

When the Day 3 differential-peak table exists, join ChIP-seq and RNA-seq effect estimates by peak_id and gene_id.

Add:

if (file.exists(peak_de_file)) {
  peak_de <- read.delim(peak_de_file, check.names = FALSE)

  peak_de_small <- peak_de[, c(
    "peak_id", "log2FoldChange", "padj", "significant"
  )]

  names(peak_de_small)[names(peak_de_small) == "log2FoldChange"] <- "chip_log2FoldChange"
  names(peak_de_small)[names(peak_de_small) == "padj"] <- "chip_padj"
  names(peak_de_small)[names(peak_de_small) == "significant"] <- "chip_significant"

  rna_chip <- merge(integrated, peak_de_small, by = "peak_id", all.x = TRUE)
  names(rna_chip)[names(rna_chip) == "log2FoldChange"] <- "rna_log2FoldChange"
  names(rna_chip)[names(rna_chip) == "padj"] <- "rna_padj"

  write.table(
    rna_chip,
    file.path(table_dir, "rna_chip_peak_integration.tsv"),
    sep = "\t", quote = FALSE, row.names = FALSE
  )

  plot_dt <- rna_chip[
    is.finite(rna_chip$rna_log2FoldChange) &
      is.finite(rna_chip$chip_log2FoldChange),
    , drop = FALSE
  ]

  if (nrow(plot_dt) > 0) {
    effect_plot <- ggplot(plot_dt, aes(chip_log2FoldChange, rna_log2FoldChange)) +
      geom_hline(yintercept = 0, linetype = 2) +
      geom_vline(xintercept = 0, linetype = 2) +
      geom_point(alpha = 0.7) +
      theme_bw() +
      labs(
        x = "ChIP-seq peak log2 fold change",
        y = "RNA-seq gene log2 fold change"
      )

    ggsave(
      file.path(plot_dir, "rna_vs_chip_log2foldchange.pdf"),
      effect_plot,
      width = 6, height = 5
    )
  }
}

The four quadrants are descriptive, not automatically activating/repressing mechanisms. Condition-dependent occupancy and expression can be related through many direct and indirect processes.

10. Retrieve peak DNA from the FASTA

FaFile keeps the genome on disk. scanFa() retrieves only the requested GRanges intervals and returns a DNAStringSet.

Add:

open(genome)
peak_sequences <- scanFa(genome, param = peaks)
close(genome)

names(peak_sequences) <- peaks$peak_id
class(peak_sequences)
peak_sequences[1:3]

The objects now have complementary roles:

peaks          = where the intervals are
peak_sequences = which DNA bases occur in those intervals

11. Calculate GC fraction and CpG counts

GC fraction is the proportion of bases that are G or C. CpG count is the number of exact CG dinucleotides.

Add:

base_counts <- letterFrequency(
  peak_sequences,
  letters = c("A", "C", "G", "T"),
  as.prob = FALSE
)

sequence_width <- width(peak_sequences)
gc_fraction <- (base_counts[, "G"] + base_counts[, "C"]) / sequence_width
cpg_count <- vcountPattern("CG", peak_sequences, fixed = TRUE)

sequence_table <- data.frame(
  peak_id = names(peak_sequences),
  width = sequence_width,
  A = base_counts[, "A"],
  C = base_counts[, "C"],
  G = base_counts[, "G"],
  T = base_counts[, "T"],
  GC_fraction = gc_fraction,
  CpG_count = cpg_count,
  CpG_per_100bp = 100 * cpg_count / sequence_width
)

write.table(
  sequence_table,
  file.path(table_dir, "peak_sequence_composition.tsv"),
  sep = "\t", quote = FALSE, row.names = FALSE
)

Plot simple distributions:

gc_plot <- ggplot(sequence_table, aes(GC_fraction)) +
  geom_histogram(bins = 30) +
  theme_bw() +
  labs(x = "GC fraction", y = "Number of peaks")

ggsave(
  file.path(plot_dir, "peak_GC_fraction.pdf"),
  gc_plot,
  width = 6, height = 4
)

cpg_plot <- ggplot(sequence_table, aes(CpG_per_100bp)) +
  geom_histogram(bins = 30) +
  theme_bw() +
  labs(x = "CpG dinucleotides per 100 bp", y = "Number of peaks")

ggsave(
  file.path(plot_dir, "peak_CpG_density.pdf"),
  cpg_plot,
  width = 6, height = 4
)

Sequence composition can help diagnose motif and background effects. It does not by itself show protein binding or regulatory function.

13. What to keep from this optional day

The transferable ideas are more important than the exact thresholds:

  • genomic interval operations should be done with interval-aware objects;
  • nearest-gene and promoter-overlap annotations answer different questions;
  • strand changes the location of an upstream promoter window;
  • a Hits object stores relationships between interval sets;
  • an indexed FASTA can return only the requested sequences;
  • DNA sequence composition is a property of the intervals, not evidence of regulation;
  • ChIP-seq binding plus RNA-seq change generates a hypothesis, not a proof.

scanFa() fails FASTA index is absent or sequence names differ genome.fa.fai and seqlevelsInUse(peaks)
A peak maps to two promoters compact/divergent bacterial gene organization retain both links and interpret biologically
