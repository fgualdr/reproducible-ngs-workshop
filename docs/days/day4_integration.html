Optional Day 4 - Basic RNA-seq and ChIP-seq integration in R

GRanges, untreated RNA-seq, WT-specific peaks and sequence composition

ImportantThis entire page is optional

Day 4 is an optional extension for students who want to practise basic genomic integration in R. It is not required to complete the core FASTQ-to-result workflows from Days 1–3.

1. Aim

Day 4 uses one deliberately narrow case study so that students can integrate results even if they completed the older Day 2 RNA-seq analysis.

We combine:

  • the untreated RNA-seq WT versus ΔHP1021 contrast stored in the legacy deseq2_results.tsv file;
  • the updated Day 3 ChIP-seq peaks already filtered as WT-specific versus ΔHP1021;
  • the common GFF3 annotation and reference genome used throughout the workshop.

The treated RNA-seq comparison is kept as a separate analysis and is not merged with the untreated results in this exercise.

Day 4 therefore asks a focused question:

Where are the WT-specific ChIP-seq peaks, which ORFs are closest to them, and which of those ORFs are differentially expressed in untreated WT versus ΔHP1021?

By the end, you should be able to explain:

  • why data.frame, GRanges, Hits, FaFile and DNAStringSet represent different objects;
  • how the Day 3 WT-specific BED and Day 1 GFF3 become interval-aware GRanges objects;
  • how distanceToNearest() answers a different question from findOverlaps();
  • how to calculate the distance from each WT-specific peak to the nearest ORF and to the nearest untreated RNA-seq DEG;
  • how to decorate a peak with the untreated RNA-seq statistics of its closest ORF;
  • how ORF and promoter overlaps define a simple intragenic / promoter-proximal / intergenic summary;
  • how to calculate GC fraction and CpG density for each selected peak;
  • why ChIP-seq proximity plus differential expression remains a candidate regulatory relationship rather than proof of direct regulation.

3. The four object types used today

R object Represents Typical operation
data.frame rectangular statistics or metadata filter, sort, merge, match
GRanges genomic intervals plus metadata overlap, nearest, distance, promoter windows
Hits index pairs connecting two interval sets query and subject extraction
FaFile / DNAStringSet indexed genome on disk / sequences in memory retrieve bases, count letters and motifs

The distinction matters. A data.frame knows that a column is named start, but it does not know that chromosome, start, end and strand form a genomic interval. GRanges does.

5.1 Prepare the untreated RNA-seq result and define DEGs

The legacy deseq2_results.tsv is used as a single contrast table. We do not merge it with the treated RNA-seq result.

Add:

required_rna_columns <- c("gene_id", "log2FoldChange", "padj")
missing_rna_columns <- setdiff(required_rna_columns, names(rna))

if (length(missing_rna_columns) > 0) {
  stop(
    "RNA-seq result is missing required columns: ",
    paste(missing_rna_columns, collapse = ", ")
  )
}

rna$gene_id <- as.character(rna$gene_id)

rna$is_de <- !is.na(rna$padj) &
  !is.na(rna$log2FoldChange) &
  rna$padj < alpha &
  abs(rna$log2FoldChange) >= lfc_cutoff

write.table(
  rna,
  file.path(table_dir, "rna_untreated_WT_vs_DeltaHP1021.tsv"),
  sep = "\t", quote = FALSE, row.names = FALSE
)

cat("Untreated RNA-seq genes:", nrow(rna), "\n")
cat("Untreated RNA-seq DEGs:", sum(rna$is_de), "\n")
ImportantCheck the contrast orientation

This exercise assumes that the legacy deseq2_results.tsv represents WT versus ΔHP1021 in untreated samples, so positive log2FoldChange means higher expression in WT. If an older result file was generated with the opposite DESeq2 contrast, the signs must be interpreted in the opposite direction.

5.2 Use the same gene identifier as Day 2

The updated Day 3 WT_specific_vs_DeltaHP1021.bed is a three-column BED. Reconstruct the same coordinate-based peak_id used in the matching Day 3 differential-peak TSV:

peaks$peak_id <- paste0(
  as.character(seqnames(peaks)), ":", start(peaks) - 1, "-", end(peaks)
)
names(peaks) <- peaks$peak_id

For the ORFs, keep the identifier logic deliberately simple. In Day 2, featureCounts used the GFF3 ID attribute (-g ID). The gene_id column in the DESeq2 result therefore comes from the same GFF3 identifier.

We simply copy the GFF3 ID field into a metadata column called gene_id so that both objects use the same column name. We do not modify the identifier values.

if (!"ID" %in% names(mcols(genes))) {
  stop("The GFF3 gene features do not contain an ID attribute")
}

genes$gene_id <- as.character(genes$ID)
names(genes) <- genes$gene_id

n_matching_ids <- sum(rna$gene_id %in% genes$gene_id)
cat("RNA-seq gene IDs matching the GFF3:", n_matching_ids, "of", nrow(rna), "\n")

if (n_matching_ids == 0) {
  stop("RNA-seq gene_id values do not match the GFF3 gene ID values")
}

Set chromosome lengths from the FASTA index and verify that the interval objects share sequence names:

genome_lengths <- setNames(width(genome_index), as.character(seqnames(genome_index)))
common_seqlevels <- intersect(names(genome_lengths), union(seqlevels(peaks), seqlevels(genes)))

seqlengths(peaks)[common_seqlevels] <- genome_lengths[common_seqlevels]
seqlengths(genes)[common_seqlevels] <- genome_lengths[common_seqlevels]

shared_sequences <- intersect(seqlevelsInUse(peaks), seqlevelsInUse(genes))
if (length(shared_sequences) == 0) {
  stop("Peaks and genes do not share chromosome names")
}

Define the annotated ORFs that are differentially expressed in the untreated RNA-seq comparison:

deg_ids <- rna$gene_id[rna$is_de]
deg_genes <- genes[genes$gene_id %in% deg_ids]

cat("WT-specific ChIP-seq peaks:", length(peaks), "\n")
cat("Annotated ORFs:", length(genes), "\n")
cat("Untreated RNA-seq DEGs used for nearest-DEG queries:", length(deg_genes), "\n")

6. Distance from each WT-specific peak to the nearest ORF and nearest DEG

distanceToNearest() answers a geometric question: for every query peak, which subject interval is closest and how far away is it? We first query all annotated ORFs, then repeat the same operation after subsetting the ORFs to untreated RNA-seq DEGs.

Add:

nearest_gene_hits <- distanceToNearest(peaks, genes, ignore.strand = TRUE)

peak_annotation <- data.frame(
  peak_id = peaks$peak_id,
  peak_chrom = as.character(seqnames(peaks)),
  peak_start = start(peaks) - 1,
  peak_end = end(peaks),
  nearest_gene_id = NA_character_,
  nearest_gene_strand = NA_character_,
  distance_to_nearest_gene = NA_integer_,
  stringsAsFactors = FALSE
)

q <- queryHits(nearest_gene_hits)
s <- subjectHits(nearest_gene_hits)

peak_annotation$nearest_gene_id[q] <- genes$gene_id[s]
peak_annotation$nearest_gene_strand[q] <- as.character(strand(genes))[s]
peak_annotation$distance_to_nearest_gene[q] <- mcols(nearest_gene_hits)$distance

Decorate the closest ORF with the untreated WT-versus-ΔHP1021 RNA-seq statistics:

rna_idx <- match(peak_annotation$nearest_gene_id, rna$gene_id)

peak_annotation$rna_WT_vs_Delta_log2FC <- rna$log2FoldChange[rna_idx]
peak_annotation$rna_WT_vs_Delta_padj <- rna$padj[rna_idx]
peak_annotation$nearest_gene_is_de <- rna$is_de[rna_idx]

Now calculate the nearest untreated DEG directly. This is different from asking whether the nearest ORF happens to be DE: a non-DE ORF can be closest while the closest DEG lies farther away.

peak_annotation$nearest_deg_id <- NA_character_
peak_annotation$distance_to_nearest_deg <- NA_integer_

if (length(deg_genes) > 0) {
  nearest_deg_hits <- distanceToNearest(peaks, deg_genes, ignore.strand = TRUE)
  q <- queryHits(nearest_deg_hits)
  s <- subjectHits(nearest_deg_hits)

  peak_annotation$nearest_deg_id[q] <- deg_genes$gene_id[s]
  peak_annotation$distance_to_nearest_deg[q] <- mcols(nearest_deg_hits)$distance
}

write.table(
  peak_annotation,
  file.path(table_dir, "peak_nearest_orf_and_deg.tsv"),
  sep = "\t", quote = FALSE, row.names = FALSE
)

Interpretation:

  • distance 0 means that the peak overlaps the queried ORF/DEG interval;
  • a positive distance means the peak lies outside that interval;
  • nearest ORF and nearest DEG answer different questions;
  • “nearest” does not mean “regulated.” It is a geometric annotation rule.

Plot the distance distributions:

distance_orf_plot <- ggplot(peak_annotation, aes(distance_to_nearest_gene)) +
  geom_histogram(bins = 40) +
  theme_bw() +
  labs(x = "Distance from peak to nearest ORF (bp)", y = "Number of peaks")

ggsave(
  file.path(plot_dir, "peak_to_nearest_ORF_distance.pdf"),
  distance_orf_plot, width = 7, height = 5
)

if (any(!is.na(peak_annotation$distance_to_nearest_deg))) {
  distance_deg_plot <- ggplot(
    peak_annotation[!is.na(peak_annotation$distance_to_nearest_deg), ],
    aes(distance_to_nearest_deg)
  ) +
    geom_histogram(bins = 40) +
    theme_bw() +
    labs(x = "Distance from peak to nearest untreated RNA-seq DEG (bp)", y = "Number of peaks")

  ggsave(
    file.path(plot_dir, "peak_to_nearest_DEG_distance.pdf"),
    distance_deg_plot, width = 7, height = 5
  )
}

7. ORF overlap, promoter overlap and simple genomic context

Nearest-neighbour queries always return a closest feature when one exists. Overlap queries answer a different question: does the peak actually intersect an ORF body or a promoter window?

For this exercise, define a strand-aware promoter as 500 bp upstream and 100 bp downstream of the annotated gene start:

promoter_ranges <- promoters(genes, upstream = 500, downstream = 101)
promoter_ranges <- trim(promoter_ranges)
promoter_ranges$gene_id <- genes$gene_id

For a +-strand gene, upstream extends toward smaller coordinates. For a --strand gene, upstream extends toward larger coordinates.

7.1 Explicit peak-ORF and peak-promoter overlap tables

Add:

orf_hits <- findOverlaps(peaks, genes, ignore.strand = TRUE)

orf_table <- data.frame(
  peak_id = peaks$peak_id[queryHits(orf_hits)],
  gene_id = genes$gene_id[subjectHits(orf_hits)],
  gene_strand = as.character(strand(genes))[subjectHits(orf_hits)]
)

write.table(
  orf_table,
  file.path(table_dir, "peak_ORF_overlaps.tsv"),
  sep = "\t", quote = FALSE, row.names = FALSE
)

promoter_hits <- findOverlaps(peaks, promoter_ranges, ignore.strand = TRUE)

promoter_table <- data.frame(
  peak_id = peaks$peak_id[queryHits(promoter_hits)],
  peak_chrom = as.character(seqnames(peaks))[queryHits(promoter_hits)],
  peak_start = start(peaks)[queryHits(promoter_hits)] - 1,
  peak_end = end(peaks)[queryHits(promoter_hits)],
  gene_id = promoter_ranges$gene_id[subjectHits(promoter_hits)],
  promoter_start = start(promoter_ranges)[subjectHits(promoter_hits)] - 1,
  promoter_end = end(promoter_ranges)[subjectHits(promoter_hits)],
  gene_strand = as.character(strand(promoter_ranges))[subjectHits(promoter_hits)]
)

write.table(
  promoter_table,
  file.path(table_dir, "peak_promoter_overlaps.tsv"),
  sep = "\t", quote = FALSE, row.names = FALSE
)

A peak can overlap more than one promoter or ORF in a compact bacterial genome. Keep those one-to-many relationships rather than forcing one annotation prematurely.

7.2 A simple mutually exclusive context for visualization

For a compact summary, classify every WT-specific peak using this priority:

  1. intragenic if it overlaps at least one annotated ORF;
  2. promoter-proximal if it does not overlap an ORF but overlaps at least one promoter window;
  3. intergenic otherwise.

The raw overlap flags are retained, so the pie chart does not replace the more detailed overlap tables.

peak_annotation$overlaps_orf <- countOverlaps(peaks, genes, ignore.strand = TRUE) > 0
peak_annotation$overlaps_promoter <- countOverlaps(
  peaks, promoter_ranges, ignore.strand = TRUE
) > 0

peak_annotation$genomic_context <- ifelse(
  peak_annotation$overlaps_orf,
  "intragenic",
  ifelse(peak_annotation$overlaps_promoter, "promoter-proximal", "intergenic")
)

write.table(
  peak_annotation,
  file.path(table_dir, "peak_annotation.tsv"),
  sep = "\t", quote = FALSE, row.names = FALSE
)

context_counts <- as.data.frame(table(peak_annotation$genomic_context))
names(context_counts) <- c("context", "n_peaks")
context_counts$fraction <- context_counts$n_peaks / sum(context_counts$n_peaks)

write.table(
  context_counts,
  file.path(table_dir, "peak_genomic_context_counts.tsv"),
  sep = "\t", quote = FALSE, row.names = FALSE
)

context_plot <- ggplot(context_counts, aes(x = "", y = n_peaks, fill = context)) +
  geom_col(width = 1) +
  coord_polar(theta = "y") +
  theme_void() +
  labs(fill = "Peak context")

ggsave(
  file.path(plot_dir, "peak_genomic_context_pie.pdf"),
  context_plot, width = 6, height = 5
)

8. Promoter-associated peaks and untreated RNA-seq DEGs

The promoter overlap produces explicit peak-to-ORF relationships. Join those relationships to the untreated WT-versus-ΔHP1021 RNA-seq statistics by gene_id.

Add:

integrated <- merge(promoter_table, rna, by = "gene_id", all.x = TRUE)

integrated$candidate_class <- ifelse(
  !is.na(integrated$is_de) & integrated$is_de,
  "untreated DE gene with WT-specific promoter-overlapping peak",
  "WT-specific promoter-overlapping peak without untreated DEG evidence"
)

write.table(
  integrated,
  file.path(table_dir, "promoter_peak_rnaseq_integration.tsv"),
  sep = "\t", quote = FALSE, row.names = FALSE
)

candidate_targets <- integrated[
  !is.na(integrated$is_de) & integrated$is_de,
  , drop = FALSE
]

candidate_targets <- candidate_targets[order(candidate_targets$padj), , drop = FALSE]

write.table(
  candidate_targets,
  file.path(table_dir, "candidate_regulatory_relationships.tsv"),
  sep = "\t", quote = FALSE, row.names = FALSE
)

The phrase candidate regulatory relationship is deliberate. WT-specific promoter-proximal occupancy plus differential expression in the untreated WT-versus-ΔHP1021 comparison is stronger combined evidence than either result alone, but it does not establish causality or distinguish direct from indirect effects.

9. Add the matching Day 3 WT-versus-ΔHP1021 peak statistics

The BED used in this Day 4 exercise already contains only peaks that passed the Day 3 WT-specific filter. The matching WT_specific_vs_DeltaHP1021.tsv contains the ChIP-seq log2FoldChange and adjusted p-value for those same intervals.

Because the BED is three-column, we reconstructed its coordinate peak_id in Section 5.2. That identifier matches the peak_id stored in the TSV.

Add:

if (file.exists(peak_de_file)) {
  peak_de <- read.delim(peak_de_file, check.names = FALSE)

  peak_de_small <- peak_de[, c("peak_id", "log2FoldChange", "padj")]
  names(peak_de_small)[2:3] <- c("chip_WT_vs_Delta_log2FC", "chip_WT_vs_Delta_padj")

  peak_annotation_chip <- merge(
    peak_annotation,
    peak_de_small,
    by = "peak_id",
    all.x = TRUE,
    sort = FALSE
  )

  write.table(
    peak_annotation_chip,
    file.path(table_dir, "peak_annotation_with_chip_statistics.tsv"),
    sep = "\t", quote = FALSE, row.names = FALSE
  )

  plot_dt <- peak_annotation_chip[
    is.finite(peak_annotation_chip$rna_WT_vs_Delta_log2FC) &
      is.finite(peak_annotation_chip$chip_WT_vs_Delta_log2FC),
    , drop = FALSE
  ]

  if (nrow(plot_dt) > 0) {
    effect_plot <- ggplot(
      plot_dt,
      aes(chip_WT_vs_Delta_log2FC, rna_WT_vs_Delta_log2FC)
    ) +
      geom_hline(yintercept = 0, linetype = 2) +
      geom_vline(xintercept = 0, linetype = 2) +
      geom_point(alpha = 0.7) +
      theme_bw() +
      labs(
        x = "ChIP-seq log2 fold change (WT / ΔHP1021)",
        y = "Nearest-ORF RNA-seq log2 fold change (WT / ΔHP1021, untreated)"
      )

    ggsave(
      file.path(plot_dir, "nearest_ORF_RNA_vs_ChIP_log2foldchange.pdf"),
      effect_plot, width = 6, height = 5
    )
  }
}

The four quadrants are descriptive. A WT-specific ChIP peak near an ORF whose expression changes between WT and ΔHP1021 is a useful regulatory hypothesis, but binding and expression can still be related through direct activation, repression, indirect regulatory cascades, or no causal relationship at all.

10. Retrieve WT-specific peak DNA from the FASTA

FaFile keeps the genome on disk. scanFa() retrieves only the requested GRanges intervals and returns a DNAStringSet.

Add:

open(genome)
peak_sequences <- scanFa(genome, param = peaks)
close(genome)

names(peak_sequences) <- peaks$peak_id
class(peak_sequences)
peak_sequences[1:3]

The objects now have complementary roles:

peaks          = where the intervals are
peak_sequences = which DNA bases occur in those intervals

11. Calculate GC fraction and CpG counts per peak

GC fraction is the proportion of bases that are G or C. CpG count is the number of exact CG dinucleotides.

Add:

base_counts <- letterFrequency(
  peak_sequences,
  letters = c("A", "C", "G", "T"),
  as.prob = FALSE
)

sequence_width <- width(peak_sequences)
gc_fraction <- (base_counts[, "G"] + base_counts[, "C"]) / sequence_width
cpg_count <- vcountPattern("CG", peak_sequences, fixed = TRUE)

sequence_table <- data.frame(
  peak_id = names(peak_sequences),
  width = sequence_width,
  A = base_counts[, "A"],
  C = base_counts[, "C"],
  G = base_counts[, "G"],
  T = base_counts[, "T"],
  GC_fraction = gc_fraction,
  CpG_count = cpg_count,
  CpG_per_100bp = 100 * cpg_count / sequence_width
)

sequence_table$genomic_context <- peak_annotation$genomic_context[
  match(sequence_table$peak_id, peak_annotation$peak_id)
]
sequence_table$nearest_gene_id <- peak_annotation$nearest_gene_id[
  match(sequence_table$peak_id, peak_annotation$peak_id)
]

write.table(
  sequence_table,
  file.path(table_dir, "peak_sequence_composition.tsv"),
  sep = "\t", quote = FALSE, row.names = FALSE
)

Plot simple distributions:

gc_plot <- ggplot(sequence_table, aes(GC_fraction)) +
  geom_histogram(bins = 30) +
  theme_bw() +
  labs(x = "GC fraction", y = "Number of peaks")

ggsave(
  file.path(plot_dir, "peak_GC_fraction.pdf"),
  gc_plot, width = 6, height = 4
)

cpg_plot <- ggplot(sequence_table, aes(CpG_per_100bp)) +
  geom_histogram(bins = 30) +
  theme_bw() +
  labs(x = "CpG dinucleotides per 100 bp", y = "Number of peaks")

ggsave(
  file.path(plot_dir, "peak_CpG_density.pdf"),
  cpg_plot, width = 6, height = 4
)

Sequence composition can help diagnose motif and background effects. It does not by itself show protein binding or regulatory function.

13. What to keep from this optional day

The transferable ideas are more important than the exact thresholds:

  • Day 4 deliberately integrates one RNA-seq contrast at a time; untreated and treated DESeq2 results are not merged into one table;
  • this case study uses the untreated WT-versus-ΔHP1021 RNA-seq result together with Day 3 peaks already selected as WT-specific versus ΔHP1021;
  • Day 2 gene identifiers come from the GFF3 ID attribute, so Day 4 uses that same ID directly for annotation matching;
  • genomic interval operations should be done with interval-aware objects;
  • nearest ORF, nearest DEG, ORF overlap and promoter overlap answer different questions;
  • strand changes the location of an upstream promoter window;
  • a Hits object stores relationships between interval sets;
  • a peak can be decorated with the statistics of its closest ORF without implying causality;
  • intragenic / promoter-proximal / intergenic is a useful summary, but detailed one-to-many overlaps should still be retained;
  • an indexed FASTA can return only the requested sequences;
  • GC and CpG content are properties of the peak sequences, not evidence of regulation;
  • WT-specific ChIP-seq binding plus untreated RNA-seq change generates a hypothesis, not a proof.
