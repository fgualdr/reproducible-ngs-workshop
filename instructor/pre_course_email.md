# Pre-course email template

Subject: Reproducible NGS workshop - setup before Day 1

Dear students,

Before the first meeting, please complete Day 0 setup from the course website. Install Git, create or verify your GitHub account, install VS Code, and install Docker Desktop or Podman Desktop.

Windows users should use Windows 10/11 with WSL2, Ubuntu terminal, and Docker Desktop with WSL2 integration.

Please send:

- operating system;
- RAM;
- CPU cores;
- approximate free disk space;
- Docker or Podman status;
- whether the container mount test succeeded;
- whether you plan to use the instructor dataset or propose your own.
