# Dry-run checklist

- Quarto site renders.
- Day 0 container mount test works with Docker or Podman.
- Student templates copy cleanly into a new repository.
- Example `.gitignore` excludes large NGS files.
- Checkpoint manifest is current.
- At least one RNA-seq count matrix is available for downstream fallback.
- At least one ChIP-seq peak file is available for downstream fallback.
- Final slides template renders.
- Instructor knows which optional sections can be skipped.
