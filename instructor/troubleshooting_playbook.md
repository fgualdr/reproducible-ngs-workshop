# Troubleshooting playbook

## Wi-Fi failure

Use pre-downloaded metadata and checkpoints. Do not start large downloads.

## Docker or Podman failure

Keep the student on Git/GitHub, metadata, Quarto, and checkpoint analysis while fixing the runtime separately.

## Windows WSL2 failure

Move the student to checkpoint mode or pair with another student. Avoid supporting PowerShell, CMD, Git Bash, and native Windows paths equally.

## Insufficient disk

Delete temporary FASTQ/BAM duplicates outside Git. Use reduced datasets or checkpoints.

## Bioconductor package failure

Use the R container, Codespaces, or checkpoint outputs. Record the backend switch.

## Dataset download failure

Use ENA URLs, instructor cache, or checkpoint files. Do not let download debugging consume the session.
