# Final 3-slide rubric

| Slide | Expected content |
|---|---|
| 1. Data and design | Biological question, organism, accessions, samples, replicates, limitations |
| 2. Workflow and QC | Analysis route, key tools, QC outcomes, checkpoint use if any; explicitly distinguishes the WT-only teaching ChIP workflow from the published WT/ΔHP1021 `csaw`/`edgeR` + MACS3 analysis |
| 3. Biological result | Main RNA-seq result, main ChIP-seq result, candidate integration, honest caveat |

Assessment prioritizes reproducibility, clarity, correct workflow description, appropriate figures, and restrained interpretation.
