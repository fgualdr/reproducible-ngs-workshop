# Repository assessment rubric

| Criterion | Excellent | Adequate | Needs work |
|---|---|---|---|
| Organization | Clear folders, README, metadata, scripts, reports, results | Mostly organized | Ad hoc or hard to navigate |
| Metadata | Complete sample/accession/reference records | Minor gaps | Missing or inconsistent |
| Git practice | Meaningful commits and correct `.gitignore` | Some useful commits | Large data committed or weak history |
| Reproducibility | Commands, backend, parameters, and checkpoints documented | Partially documented | Cannot reconstruct workflow |
| RNA-seq/ChIP-seq methods | Methods match data and limitations stated | Minor methodological gaps | Incorrect or unsupported methods |
| Interpretation | Claims tied to data and uncertainty | Some overclaiming | Unsupported biological conclusions |
